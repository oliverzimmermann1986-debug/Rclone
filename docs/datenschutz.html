Datenschutzerklärung

Stand: 24. August 2026

Keine Datenerfassung durch den Entwickler

Rclone Sync verwendet keine Analyse-, Werbe- oder Trackingdienste. Der Entwickler erhält über die App keine personenbezogenen Daten, Nutzungsdaten, Dateinamen oder Sicherungsinhalte.

Verbindung zum eigenen Server

Die von dir eingegebene Serveradresse und der Benutzername werden lokal auf deinem Gerät gespeichert. Das Passwort wird nicht dauerhaft gespeichert. Anfragen gehen ausschließlich an die von dir angegebene Rclone-Sync-Installation. Für Betrieb und Datenschutz dieses Servers ist dessen Betreiber verantwortlich.

Push-Mitteilungen

Wenn du Mitteilungen aktivierst, wird ein von Apple ausgegebener Geräte-Token an deinen eigenen Rclone-Sync-Server übertragen. Dieser verwendet Apple Push Notification Service ausschließlich, um Sicherungs- und Prüffehler zu melden. Die Funktion ist optional und kann in iOS deaktiviert werden.

Lokale Vorschau

Die integrierte Demo verwendet ausschließlich mitgelieferte Beispieldaten und stellt keine Netzwerkverbindung her.

Kontakt

Datenschutzfragen können über das öffentliche Supportsystem auf GitHub gestellt werden. Bitte veröffentliche dort keine Passwörter, Tokens, privaten Serveradressen oder unredigierten Protokolle.
