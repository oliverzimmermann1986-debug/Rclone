Support

Deine Sicherungen. Klar im Blick.

Rclone Sync verbindet dein iPhone mit deiner selbst gehosteten Rclone-Sync-Installation. Die App zeigt Datenwege, Zeitpläne, Läufe und den Systemzustand in einer nativen Oberfläche.

Hilfe erhalten

Prüfe zuerst Serveradresse, Netzwerkfreigabe und den Status deiner Rclone-Sync-Installation. Für reproduzierbare Fehler kannst du in der App unter System → Betrieb & Wartung ein redigiertes Support-Bundle erstellen.

Supportanfrage auf GitHub erstellen

Wichtig

Rclone Sync ist ein Client für eine eigene Serverinstallation. Die App stellt keinen Cloudspeicher bereit und überträgt keine Sicherungsdateien über Dienste des App-Entwicklers.
